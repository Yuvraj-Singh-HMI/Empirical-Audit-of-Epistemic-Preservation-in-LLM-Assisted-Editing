# Empirical Audit of Epistemic Preservation in LLM-Assisted Editing

**Author:** Yuvraj Singh Rajawat (IIIT Allahabad)  
**Target Venue:** ACM Computing Surveys (CSUR)

## 📌 Problem Statement
When Large Language Models (LLMs) are used as scientific editing assistants, they frequently suffer from "parametric memory override," altering cautious, correlational scientific claims (e.g., "is associated with") into unwarranted causal assertions (e.g., "causes"). 

This repository contains the code and dataset to evaluate automated metrics for detecting these dangerous **epistemic shifts**. We proposed an asymmetrical Natural Language Inference (NLI) metric ($\Delta_{\text{epistemic}}$) but empirically demonstrate that deep contextual embedding divergence (**BERTScore**) provides a vastly superior, rule-free standard for auditing causal escalations in LLM-edited text (ROC-AUC = 0.9518).

## 📊 Dataset Preparation
**Path:** `data/custom_epistemic_suite.csv`

The dataset consists of 100 observational biomedical claims sourced programmatically via the NCBI Entrez API, expanded into 100 perfectly matched triplets (300 rows total) using a prompted LLM. 

**Schema:**
*   `pair_id`: Unique identifier (P001 to P100).
*   `condition`: `original` (Base claim), `paraphrase` (Label 0), or `escalated` (Label 1).
*   `text`: The biomedical string.

**Integrity Note:** Anomalies in pairs P019, P060, and P093 (identical strings generated by the LLM) have been manually corrected in this repository to feature explicit causal escalations.

## ⚠️ Limitations & Blind Spots
1.  **Synthetic Constraints:** The diagnostic suite evaluates constrained, single-verb correlational-to-causal escalations. Real-world LLM editing often introduces multi-clause structural changes.
2.  **NLI Domain Collapse:** General-domain cross-encoders (e.g., `deberta-v3-large`) fail entirely on this task because they treat biomedical verb swaps as neutral contradictions rather than epistemic entailments.
3.  **LLM Context Overload:** Attempting to force entailment logic via Generative LLM prompting (Pathway C) fails on dense biomedical text, leading to synonym hallucinations and ignored escalations.
